# Code of Conduct

open-fp follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep criticism about the work, not the person. Harassment, personal attacks, discriminatory language and publishing other people's private information are not acceptable anywhere in the project: issues, pull requests, discussions and any other project space.

## Reporting

If someone's behaviour concerns you, contact the maintainer, [@jewbetcha](https://github.com/jewbetcha), privately using the email address on their GitHub profile. Reports are kept confidential. The maintainer may warn, temporarily ban or permanently ban anyone who breaks this code, following the enforcement guidelines in the Contributor Covenant.
